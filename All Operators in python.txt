6. Identity Operator : 

An identity operator checks whether two variables refer to the same object in memory.
In simple words:
is asks: "Are these two variables referring to the exact same object?"
Whereas == asks:
"Do these two objects have equal values?"
This is the most important difference.

imp Note : == compares values. is compares identity.

is
is not

is → Are both variables referring to the same object?
is not → Are both variables referring to different objects?



| `==` | `is` | `is not` |
|---|---|---|
| Compares values | Compares identity | Compares identity |
| Asks "same value?" | Asks "same object?" | Asks "different object?" |
| Commonly used for value comparison | Used when object identity matters | Used when different identity matters |
| Example: `a == b` | Example: `a is b` | Example: `a is not b` |

note : 

==       → SAME VALUE?
is       → SAME OBJECT?
is not   → DIFFERENT OBJECT?



7. Bitwise Operator : 

Bitwise operators work bit by bit on integers. 
number is represented in binary (0 and 1).


Operator	Name	Example
&	Bitwise AND	5 & 3
|	Bitwise OR      5 | 3
^	Bitwise XOR	5 ^ 3
~	Bitwise NOT	~5
<<	Left Shift	5 << 1
>>	Right Shift	20 >> 1


&   → BOTH
|   → ANY ONE
^   → DIFFERENT
~   → REVERSE
<<  → LEFT
>>  → RIGHT
