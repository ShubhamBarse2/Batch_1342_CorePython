An f-string (formatted string literal) is a string in Python that starts with the letter f or F and allows you to embed expressions, variables, and function calls directly inside the string by wrapping them in curly braces {}.

 ref code : 

name = "Alice"
age = 30

# Using an f-string

message = f"Hello, my name is {name} and I am {age} years old."
print(message)  

# Output: Hello, my name is Alice and I am 30 years old.

x = 10
y = 5

print(f"The sum of {x} and {y} is {x + y}.")
# Output: The sum of 10 and 5 is 15.
