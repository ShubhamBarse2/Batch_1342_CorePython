Operator: The symbol or keyword that tells Python what operation to perform.
Operation: The actual action performed using an operator on operands.

1. Arithmetic : 

it is used to represent an Mathematical calculations  

+,-,*,/,%,//(Floor Division),**(Exponential) : 



+

Addition
Adds two values
10 + 3 = 13

-

Subtraction
Subtracts the second value from the first
10 - 3 = 7

*

Multiplication
Multiplies two values
10 * 3 = 30

/

Division
Returns the division result as a float
10 / 3 = 3.3333...


//

Floor division
Returns the quotient rounded down
10 // 3 = 3


%

Modulus
Returns the remainder
10 % 3 = 1


**

Exponentiation
Raises a value to a power
2 ** 3 = 8
