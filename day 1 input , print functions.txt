Important Points to Remember

# is used for a single-line comment.
Triple quotes can be used for multi-line explanatory text.
\n moves the output to a new line.
\' prints a single quote.
\" prints a double quote.
sep separates multiple values in print().
end controls what is printed at the end of print().
Python keywords have predefined meanings.
import is used to import a module.
String concatenation is performed using +.
Direct str + int concatenation is not allowed.
str() can convert a value into a string.
Complex numbers use j for the imaginary part.
input() returns a string by default.
int(), float(), and complex() can be used for type conversion.

Most Important Formula for Beginners

input()
   ↓
Always String
   ↓
Type Conversion
   ↓
Required Data Type

Example:

age = int(input("Enter age: "))

means:

input() → Take input
int()   → Convert input into integer
age     → Store the value
